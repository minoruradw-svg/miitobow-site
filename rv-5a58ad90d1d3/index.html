Screenshot Translator — Sensitive Permissions Demo

App: スクショで翻訳 (Screenshot Translator) · package com.miitobow.screenshot_translator
Private demo for Google Play review. Not linked from anywhere; unlisted.

What this video shows

  1. The user opens the app and turns on the optional “Screenshot auto-detect” switch (off by default).
  2. A persistent foreground-service notification (“Standing by”) appears while the feature is on.
  3. The user opens another app (Android Settings) and takes a screenshot.
  4. The app detects the newly saved screenshot and offers translation (“Screenshot detected — tap to translate”).
  5. The user taps “Translate”; the screenshot opens in the app’s range/language screen.
  6. The text is recognized and translated entirely on the device (English → Japanese), shown overlaid on the image.

Why each sensitive permission is required

READ_MEDIA_IMAGES (access to all photos)
The core purpose of the auto-detect feature is to notice a screenshot the moment the user saves it, in any app. This requires observing newly added images in the device’s media store. The Android photo picker cannot be used, because the picker only returns a file the user manually selects — it cannot detect a new screenshot automatically, which is the entire feature. Access is used only while the user has turned the feature on.
FOREGROUND_SERVICE_SPECIAL_USE
Detecting a screenshot right after it is taken requires a short-lived background watcher that runs only while the feature is enabled. It runs as a foreground service with an ongoing notification so the user always knows it is active, and it stops completely when the user turns the feature off.

Privacy

  • OCR and translation run fully on-device; images and text are never uploaded or transmitted.
  • The feature is off by default and can be turned off at any time, which fully stops the watcher.
  • Privacy policy: https://minoruradw-svg.github.io/privacy/privacy-policy.html (see Section 7).

Note: this recording was captured on an Android emulator. On the emulator the detection is shown via a notification; on physical devices the app can also show an on-screen “Translate” confirmation popup when the optional “display over other apps” permission is granted. Both paths exercise the same READ_MEDIA_IMAGES and foreground-service usage.
