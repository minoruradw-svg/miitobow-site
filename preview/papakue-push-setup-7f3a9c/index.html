通知の用意（.p8）手順書

パーティの「おねがい」や「パーティクエスト」が届いたとき、相手のスマホが鳴るようにするための設定です。
所要時間は、約15分。いちばん上から順に、押すだけで終わります。コードの用意は、もう済んでいます。

⚠ .p8 のファイルは、秘密の鍵です。チャット・メール・スクリーンショット・GitHub には、貼らない・載せない。
Firebase の画面に、直接アップロードするだけにしてください（私＝Claude にも、中身は見せないでください）。

先に用意するもの

  • パソコンのブラウザ（Mac でも Windows でも OK。最初から最後まで、同じパソコンで行うのが楽です）
  • Apple Developer のアカウント（いつもの Apple ID）
  • Firebase のアカウント（papakue-dev を開ける Google アカウント）
1

Apple：アプリの「通知」をオンにする

約3分
  1. ブラウザで developer.apple.com/account を開き、サインインする。
  2. Certificates, IDs & Profiles（証明書、ID、プロファイル）を押す。
  3. 左のメニューの Identifiers（識別子）を押す。
  4. 一覧から com.miitobow.todoQuest を探して押す（パパクエのアプリです。Watch や Widget のものではなく、末尾が何も付かないもの）。
  5. 下へスクロールして、機能の一覧から Push Notifications を探し、チェックを入れる。
  6. 右上の Save（保存）を押す。確認が出たら Confirm。
すでにチェックが入っていたら、何もせず、次へ進んで大丈夫です。
2

Apple：通知用の鍵（.p8）を作る

約4分
  1. 同じ画面の左のメニューで Keys（キー）を押す。
  2. 青い ＋（新しいキー）を押す。
  3. Key Name（名前）に、papakuepush と入れる（ハイフン・スペース・記号は使えません。半角の英数字だけ）。
  4. 一覧から Apple Push Notifications service (APNs) にチェックを入れる。
  5. 赤い文字「This service must have environment and type configured」が出て、Continue が押せない時は、APNs の行の右にある Configure を押す。開いた画面で、Environment（環境）＝ Sandbox & Production、Key Type（種類）＝ Team Scoped (All Topics) を選び、Save。赤い文字が消えて、Continue が押せるようになる。
  6. Continue → Register（登録）を押す。
  7. Download（ダウンロード）を押して、.p8 のファイルを保存する。
    ⚠ ダウンロードできるのは、この1回だけです。画面を閉じる前に、必ず保存してください。
  8. 保存先は、パパクエのフォルダの外にします。おすすめ：P:\work\secrets\（なければ作る）。ファイル名は、AuthKey_XXXXXXXXXX.p8 のような形です。
  9. 画面に出ている Key ID（10文字の英数字）を、メモする。
Apple の APNs キーは、1つのアカウントで、2つまでしか作れません。「上限です」と出たら、すでにあるキーが、ほかのアプリ用に使われていないか確認してください。迷ったら、その画面を、私に見せてください。
3

Apple：Team ID を調べる

約1分
  1. Apple Developer の画面の右上の、アカウント名の下に、Team ID（10文字の英数字）が出ています。
  2. 出ていないときは、左のメニューの Membership details（メンバーシップの詳細）を開くと、Team ID があります。
  3. その10文字を、メモする。
Key ID と Team ID は、鍵そのものではないので、メモしたり、私に伝えたりして大丈夫です。
4

Firebase：鍵をアップロードする

約3分
  1. ブラウザで console.firebase.google.com を開き、papakue-dev を押す。
  2. 左上の 歯車のマーク → プロジェクトの設定 を押す。
  3. 上のタブから Cloud Messaging を押す。
  4. 下へスクロールして、Apple アプリの構成 の欄を探す。
  5. com.miitobow.todoQuest の中の、APNs 認証キー の アップロード を押す。
  6. 手順2で保存した .p8 ファイルを選ぶ。
  7. キー ID に、手順2のKey IDを入れる。チーム ID に、手順3のTeam IDを入れる。
  8. アップロード を押す。

うまくいくと、「APNs 認証キー」の欄に、キー ID が表示されます。

「APNs 開発用認証キー」と「APNs 本番用認証キー」の2つの欄があるときは、両方に、同じ .p8 を、同じ Key ID と Team ID で、アップロードしてください（開発用のビルドにも、本番用のビルドにも、通知が届くようにするためです）。
5

Mac：アプリを入れ直す

約10分（ビルドの時間）

iPhone を Mac につないで、次のコマンドを入力します（コピーして貼り付け）。

cd ~/Developer/todo-quest && git stash && git checkout m2-firebase && git pull && sh tool/mac_run.sh
  • 初めて「通知の権限」を足したビルドなので、Xcode が署名の設定を、自動で更新します。少し時間がかかります。
  • 「プロビジョニングプロファイルに、通知の権限がない」という意味のエラーが出たら、手順1が済んでいるかを確かめます。それでも出たら、そのエラーを、私に貼ってください。
6

確認：通知が鳴るか試す

約5分
  1. パーティ画面の上に、通知をオンにする が出ていたら、押して、OS の確認で「許可」する。
    （もう許可済みなら、小さく「依頼が来たら、通知でお知らせします。」と出ています。それで OK です）
  2. 2台のスマホ（あなたと奥様）で、同じパーティに入っている状態にする。
  3. どちらかが、もう一方に「おねがい」または「パーティクエスト」を送る。
  4. 受け取る側のスマホが鳴れば、成功です。アプリを閉じていても、鳴ります。
  5. 相手が「受ける」を押すと、送った側が鳴ります。
通知の文は「新しいおねがいが届きました。」などです。おねがいの題（中身）は、通知に入りません（ロック画面で、他の人に見えても困らないようにするためです）。

うまくいかないとき

症状見るところ
「通知をオンにする」が出ないすでに許可済み（小さく「通知でお知らせします」と出る）か、断られている（「設定を開く」が出る）。断られているときは、iPhone の「設定」→「パパクエ」→「通知」をオンにする。
「登録できませんでした」と出る通信を確かめる。手順4の、Firebase の鍵のアップロードが、うまくいっているか（キー ID が表示されているか）。
登録はできたのに、鳴らない手順4の Key ID と Team ID の入れ間違いが、いちばん多い原因。入れ直してアップロードし直す。それでもだめなら、Firebase の Functions の onRequestWritten のログを、私に見せる。
アプリを開いている間だけ、出ない仕様どおり、画面の上に出る設定です。出ない場合は、私に報告してください。
同じ端末で、別の人でサインインしたら、前の人の通知が来るサインアウトで、その端末の登録は外れます。外れていない場合は、報告してください。

公開する前に（今は、やらなくて大丈夫）

  • 本番用の Firebase プロジェクトを作ったら、そこにも、同じ .p8 を、同じ手順（手順4）で登録する。
  • 配布用のビルドでは、アプリの通知の設定（aps-environment）は、Xcode が自動で本番用に切り替えます。
